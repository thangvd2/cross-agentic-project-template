## Task Protocol

1. **Creating a task**: Add entry above with status "In Progress"
2. **Updating a task**: Change status, add notes
3. **Completing a task**: Mark as "Done", include summary of changes
4. **Blocked tasks**: Note the blocker and who can unblock it
5. **Session handoff**: Update task status in HANDOFF.md when switching tools
